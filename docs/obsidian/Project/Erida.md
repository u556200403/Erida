# Erida

[[Roadmap|Дорожная карта]] · [[Current State|Текущее состояние]] · [[Next Steps|Ближайшие шаги]]

Erida — desktop-first приложение для ведения локальной музыкальной библиотеки и управления плейлистами. В текущей реализации пользователь может просмотреть сохранённую библиотеку и импортировать локальные аудиофайлы; страница плейлистов пока показывает демонстрационные данные.

## Основной стек

- **Frontend:** Vue 3, Nuxt 3 в SPA-режиме, TypeScript, Pinia и Tailwind CSS.
- **Desktop shell:** Tauri 2; нативная часть написана на Rust.
- **Локальные данные:** SQLite через `rusqlite`; метаданные аудио читаются библиотекой `lofty`.
- **Проверки:** Vitest для TypeScript/Vue-кода, `cargo test` для Rust-кода в CI.

В проектных инструкциях также указан Drizzle ORM, однако на момент описания его нет ни в зависимостях, ни в исходном коде. Поэтому SQLite в текущем состоянии реализована не через Drizzle.
