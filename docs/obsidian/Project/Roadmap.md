# MVP 🎯

MVP считается достигнутым после завершения Phases 1–5.

Пользователь должен иметь возможность:

- импортировать локальную музыкальную библиотеку;
- создавать и редактировать плейлисты;
- генерировать плейлисты из библиотеки;
- импортировать внешний плейлист по ссылке;
- подключить как минимум один музыкальный сервис;
- переносить/синхронизировать плейлисты между Erida и первым поддерживаемым сервисом.
