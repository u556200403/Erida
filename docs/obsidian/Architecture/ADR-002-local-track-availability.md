# ADR-002: Доступность локального трека определяется при загрузке библиотеки

## Контекст

Файл локального трека может быть удалён, перемещён или временно недоступен. Запись при этом должна оставаться в SQLite, чтобы пользователь мог открыть её и удалить из библиотеки вручную.

## Решение

`LoadLibraryTracks` получает записи через `MusicLibraryRepository` и запрашивает доступность только для источников `local` через порт `LocalTrackAvailabilityChecker`. Его Tauri-адаптер вызывает Rust command, который проверяет metadata указанного пути. Ошибка или отрицательный результат отдельной проверки дают эфемерное состояние `unavailable`; загрузка остальных записей продолжается.

Состояние доступности не хранится в SQLite и не передаётся в репозиторий. UI получает его в read-модели и показывает метку `Unavailable`, не убирая ссылку на Track Details и действие удаления. Источники `service` получают `not-applicable` и не проверяются.

## Последствия

Нет миграции SQLite, автоматической очистки, relink, watcher или доступа UI к файловой системе. Статус обновляется при следующей загрузке библиотеки.
