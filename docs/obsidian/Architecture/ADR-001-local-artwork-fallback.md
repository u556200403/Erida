# ADR-001: Local artwork хранится в application-data cache

## Контекст

При импорте локального трека artwork может отсутствовать в metadata аудиофайла, но находиться рядом с ним в виде `cover.jpg/png` или `folder.jpg/png`.

## Решение

Поиск и копирование выполняются в Tauri/Rust. Embedded artwork сохраняет приоритет. При его отсутствии или ошибке Rust выбирает локальный файл в фиксированном порядке `cover.jpg`, `cover.png`, `folder.jpg`, `folder.png` без учёта регистра, проверяет размер и signature и копирует байты без преобразования в `artwork/local` application-data directory.

`Track` хранит только строго валидируемый относительный ref `local/<track-id>.jpg|png`. UI получает URL через существующий `ArtworkUrlResolver` и не получает файловый доступ.

## Последствия

Исходные изображения не изменяются, а artwork остаётся доступным после удаления или перемещения исходного каталога. Ошибки поиска, чтения или кэширования artwork не отменяют импорт трека.
