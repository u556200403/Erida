## Сейчас

1. **#51 — Local artwork fallback**
   - использовать embedded artwork в первую очередь;
   - при его отсутствии искать `cover.jpg/png` или `folder.jpg/png` рядом с аудиофайлом;
   - кэшировать найденное изображение в application data;
   - ошибка artwork не должна прерывать импорт трека.

## Завершение Phase 1

2. Добавить понятное поведение для отсутствующих или перемещённых исходных аудиофайлов.
3. Проверить и отполировать empty/loading/error states библиотеки.
4. Добавить навигацию `Back to Library` из Track Details.
5. Провести финальный native smoke test полного сценария Local Music Library.

Поиск, фильтрация, редактирование тегов, bulk operations и другие расширенные операции с библиотекой не входят в текущий scope Phase 1 и могут быть реализованы позже в Library Management.

## Далее

После завершения Phase 1 перейти к [[Roadmap#Phase 2 — Playlists 📋|Phase 2 — Playlists]]:

- определить доменную модель Playlist;
- добавить SQLite persistence;
- реализовать создание и удаление плейлистов;
- добавление и удаление треков из плейлиста;
- заменить текущие demo playlists реальными данными;
- реализовать базовый UI управления плейлистами.

Генерация плейлистов, импорт плейлистов по ссылке и интеграции с музыкальными сервисами выполняются на следующих этапах Roadmap, а не смешиваются с базовой реализацией Playlists.
