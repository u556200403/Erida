- определить доменную модель Playlist;
- добавить SQLite persistence;
- реализовать создание и удаление плейлистов;
- добавление и удаление треков из плейлиста;
- заменить текущие demo playlists реальными данными;
- реализовать базовый UI управления плейлистами.

Генерация плейлистов, импорт плейлистов по ссылке и интеграции с музыкальными сервисами выполняются на следующих этапах Roadmap, а не смешиваются с базовой реализацией Playlists.
